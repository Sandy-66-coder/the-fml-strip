# The FML Strip

A retro-styled vocal processing AU/VST3 plugin project for Apple Silicon macOS workflows.

## Status
- Phase 1: Plugin skeleton
- Phase 2: DSP module structure
- Phase 3: In progress
- Phase 4: GUI & meter work
- Phase 5: AU validation and release

## Project goals
- Warmth with oversampled tanh saturation
- Mud removal via dynamic bell filter
- Optical-style compression with soft knee behavior
- Air with a 12kHz shelf + parallel exciter
- Stereo width via M/S processing
- Auto gain based on RMS matching
- Retro wood/brass analog UI inspired by vintage channel strips

## Planned formats
- Audio Unit (AU)
- VST3 (optional)
- Apple Silicon macOS target

## Build notes
This initial scaffold is a JUCE-based starter and is intended to be used in Logic Pro X / Apple Silicon.
